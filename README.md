# pepperonas/tap

Homebrew formulae for my command-line projects.

```sh
brew install pepperonas/tap/hollywood     # https://hollywood.celox.io
brew install pepperonas/tap/wallstreet    # https://wallstreet.celox.io
```

| Formula | What it is | Source |
|---|---|---|
| `hollywood` | fills a terminal with Hollywood-style technobabble in tmux panes — the macOS port | [pepperonas/hollywood](https://github.com/pepperonas/hollywood) |
| `wallstreet` | live stock quotes, tickers and headlines in tmux panes | [pepperonas/wallstreet](https://github.com/pepperonas/wallstreet) |

The formulae are written by each project's `tools/tap-formula.sh` from its release: the
URL points at the release archive and the checksum is the one in its `SHA256SUMS`.
